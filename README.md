# Angular Test Project

_This project was generated using [Angular CLI](https://github.com/angular/angular-cli) version 20.3.4._

## Installer le projet / Install project

```bash
git clone git@github.com:Greg0s/learning-angular.git

cd learning-angular

npm i
```

## Lancer le projet / Start project

```bash
ng serve
```

Une fois le serveur lancé, ouvrez votre navigateur et allez à [`http://localhost:4200/`](`http://localhost:4200/`).

Once the server is running, open your browser and go to [`http://localhost:4200/`](`http://localhost:4200/`).
