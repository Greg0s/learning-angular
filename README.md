# J&J Development - Test technique - Grégoire Tinnes

_This project was generated using [Angular CLI](https://github.com/angular/angular-cli) version 20.3.4._

## Installer le projet

```bash
git clone git@github.com:Greg0s/jnjdevelopment-test-technique.git

cd jnjdevelopment-test-technique

npm i
```

## Lancer le projet

```bash
ng serve
```

Une fois le serveur lancé, ouvrez votre navigateur et allez à [`http://localhost:4200/`](`http://localhost:4200/`).
